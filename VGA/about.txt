VGA Module Collection
=====================

This folder contains a small VGA timing and driver implementation targeting classic 640x480 @ 60Hz VGA timing, along with simplified testbenches for faster simulation.
Module 4 is complete VGA driver, while modules 1-3 is modular modules. some of them can be used in other modules if they need counting for VGA pipelinig. maybe when drawing an object (a ball).



Modules
-------

1. my_VGA_frame_Gen.sv
   - Generates the horizontal and vertical frame position counters.
   - Counts through a full VGA frame using parameters HSYNC_TOT and VSYNC_TOT.
   - Produces o_hsync_frame_pos, o_vsync_frame_pos, and a frame reset signal o_w_frame_reset.

2. my_VGA_active_pulse_Gen.sv
   - Uses my_VGA_frame_Gen to generate visible-area indicators.
   - Produces o_hsync_active and o_vsync_active that are asserted when the pixel position is inside the visible region.
   - Default visible dimensions are HSYNC_ACTIVE = 640 and VSYNC_ACTIVE = 480.

3. my_VGA_sync_pulse_gen.sv
   - Uses my_VGA_frame_Gen to generate real VGA sync pulses with front porch, sync pulse, and back porch timing.
   - Produces o_hsync_pulse and o_vsync_pulse signals.
   - Uses standard VGA timing parameters by default and outputs active-low sync pulses.

4. my_VGA_driver.sv
   - Implements a full VGA timing driver in one module.
   - Counts horizontal and vertical positions and generates o_hsync_pulse, o_vsync_pulse, and o_w_frame_reset.
   - Supports parameterized visible area, porches, and sync pulse widths.

Testbenches
-----------

1. tb_my_VGA_frame_Gen.sv
   - Verifies the frame generator counters.
   - Uses the full 800x525 VGA totals in simulation.
   - Writes waveform output to `waveform.vcd`.

2. tb_my_VGA_active_pulse_Gen.sv
   - Tests the active-area pulse generator.
   - Uses reduced timing values for easier observation.
   - Writes waveform output to `Waveform.vcd`.

3. tb_my_VGA_sync_pulse_gen.sv
   - Tests the sync pulse generator and active-pulse interface.
   - Uses reduced timing values for faster simulation.
   - Writes waveform output to `Waveform.vcd`.

4. tb_my_VGA_driver.sv
   - Tests the complete VGA driver module.
   - Uses reduced timing values for faster simulation.
   - Writes waveform output to `Waveform.vcd`.

Notes
-----

- The folder is organized into core VGA timing logic and simple testbenches.
- The modules are parameterized, so the default timing is 640x480 visible area with an 800x525 total horizontal/vertical scan.
- Several testbenches use reduced timing values to speed up simulation and make waveform observation practical.
- The generated sync pulses are active-low by default, following classic VGA conventions.
